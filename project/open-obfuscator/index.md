# Open-Obfuscator

> A free and open-source obfuscator for mobile applications

Open-obfuscator is an open-source project composed of [o-mvll](https://obfuscator.re/omvll) and
[dProtect](https://obfuscator.re/dprotect).

The purpose of this project is to provide an obfuscation playground for developers and reverse engineers as
described in this blog post:
[*Open-Obfuscator: A free and open-source obfuscator for mobile applications*](/post/22-10-open-obfuscator).
