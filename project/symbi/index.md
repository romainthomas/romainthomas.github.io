# Symbi

> A dynamic trace symbolizer built on DynaMIR.

Symbi builds on DynaMIR to turn dynamic instruction traces into symbol-aware
execution data. It is the analysis-facing layer between low-level runtime events
and the higher-level context consumed by automated reverse-engineering tools.
