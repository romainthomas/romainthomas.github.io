Dynamic Binary Analysis and Obfuscated Codes

Jonathan Salwan, Romain Thomas April 8, 2016

Abstract

This presentation explains how dynamic binary analysis (DBA) can help reverse engineers understand obfuscated code. We introduce basic obfuscation techniques and demonstrate how Triton can detect opaque predicates, reconstruct control-flow graphs, recover original algorithms, and isolate sensitive data. We conclude with a demonstration and an overview of future work.
