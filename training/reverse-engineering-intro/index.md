# Introduction to Reverse Engineering

> This workshop introduces the main concepts to get started in reverse engineering

This workshop aims to provide the key concepts in reverse engineering to
address the main challenges while analyzing a binary. In particular, it provides an overview
of the compiler's optimizations, how to identify and reconstruct structures, and the methodology
to analyze large binaries.
